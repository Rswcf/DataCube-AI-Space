Data Cube AI는 40개 이상의 검증된 소스(RSS, Hacker News, YouTube)에서 AI 뉴스를 자동으로 수집·분류·요약합니다. 매일 업데이트, 8개 언어 지원, AI 에디토리얼(Why Today Matters), 자체 트렌드 모멘텀 신호, 투자 트래킹, 무료 JSON API 제공.

**라이브: [datacubeai.space](https://www.datacubeai.space)** — 가입 불필요.

## 주요 기능

- 일간·주간 뷰(테크, 투자, 팁, 영상)
- AI 에디토리얼 레이어와 자체 트렌드 모멘텀 데이터
- 8개 언어(영어 네이티브 생성, 나머지는 번역)
- 무료 개발자 API와 일간 뉴스레터
- 오픈소스(MIT), 셀프 호스팅 가능
