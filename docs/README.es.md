Data Cube AI recopila, clasifica y resume automáticamente noticias de IA de más de 40 fuentes verificadas (RSS, Hacker News, YouTube) — a diario, en 8 idiomas, con editorial de IA, señales propias de tendencias, seguimiento de inversiones y una API JSON gratuita.

**En línea en [datacubeai.space](https://www.datacubeai.space)** — sin registro.

## Destacados

- Vistas diarias y semanales (tecnología, inversión, consejos, vídeos)
- Editorial de IA y datos propios de momentum de tendencias
- 8 idiomas, generado nativamente en inglés y traducido después
- API gratuita para desarrolladores y newsletter diaria
- Código abierto (MIT), auto-hospedable
