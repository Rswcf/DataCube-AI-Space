Data Cube AI は 40 以上の検証済みソース(RSS、Hacker News、YouTube)から AI ニュースを自動で収集・分類・要約します。毎日更新、8 言語対応、AI 編集ブリーフ(Why Today Matters)、独自のトレンドモメンタム指標、投資トラッキング、無料 JSON API を提供。

**公開中: [datacubeai.space](https://www.datacubeai.space)** — 登録不要.

## 主な機能

- 日次・週次ビュー(テック、投資、Tips、動画)
- AI 編集レイヤーと独自トレンドモメンタムデータ
- 8 言語対応(英語ネイティブ生成、他言語は翻訳)
- 無料開発者 API と日刊ニュースレター
- オープンソース(MIT)、セルフホスト可能
